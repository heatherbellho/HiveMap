Confirm Archive

Archiving a hive will permanently remove it from the Field View and add it to the Hives → Archived Hives table list.
All data will be retained and this can be viewed by using the 'view' icon shown for each hive in the Archived Hives table list to open the hive details panel.
The Archived Hive can also be permanently deleted in that panel.
Data cannot be edited after archiving so make any required changes and save before then archiving.
Archiving cannot be undone.
