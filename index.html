Confirm Archive

Archiving a hive will remove it from the Field View.
All data will be retained and this can be viewed in Hives → Archived Hives in the toolbar.
It can also be viewed in other table lists that show a black Archived button.
Data cannot be edited after archiving so make any required changes and save now before archiving.
The hive cannot be restored to the active apiary. This action cannot be undone.
